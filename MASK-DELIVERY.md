# Доставка масок без пересборки приложения — спека

> Статус: **утверждено** (вариант «контент-пак»), не реализовано.
> Задача: добавить 100 масок завтра = опубликовать пак, БЕЗ сборки, БЕЗ нотаризации, БЕЗ релиза.

## Почему сейчас нельзя (корень проблемы)

1. `Masks/<id>/index.html` — это 3 строки редиректа на `Prototype/index.html?engine=1&autostart=<EffectId>`.
   Реальный код маски — `Prototype/effects/registry/<name>.js`, и он **обязан** быть импортирован +
   добавлен в массив `RAW` в `Prototype/effects/index.js`. Оба файла лежат внутри `.app`.
2. Доверие определяется **путём** (`EngineFrameReceiver.isUntrustedMaskURL`):
   бандл → доверенный; `ApplicationSupport/MEETAMASK/UserMasks` → `--untrusted`
   (нет сети, нет чтения файлов, нет ES-модулей).
   Наши маски **требуют** сети (three.js с esm.sh + модели MediaPipe) → в песочницу они не помещаются.

Вывод: недостаточно «положить папку» — нужен обновляемый контент вне бандла + его доверие.

## Решение: подписанный контент-пак

`Prototype/` + `Masks/` переезжают из «только бандл» в «бандл = дефолт, пак с CDN = свежее».
Механика доставки — как у движка (`EngineInstaller`: скачивание, распаковка в Application Support,
атомарная подмена, работа офлайн после первой загрузки).

✅ **Проверка подлинности в `EngineInstaller` теперь есть** (была дырой до v0.5): распакованная
копия проверяется `codesign --verify --strict -R` по требованию «Apple-anchored + наш Team ID +
наш bundle id» **до** перемещения на место и **до** снятия карантина, плюс сверяется контракт,
который движок объявляет в собственном `Info.plist`. Не прошло — установка отменяется, ничего
исполняемого не остаётся. Раньше подмена редиректа `dl.meetamask.com/engine` давала выполнение
произвольного кода в несэндбоксенном хосте.
Для контент-пака проверка подписи обязательна с первого дня — см. ниже.

### Хранилище

```
~/Library/Application Support/MEETAMASK/
  Engine/                     ← как сейчас
  Content/
    current -> packs/1.4.0    ← симлинк, атомарное переключение
    packs/1.4.0/
      Prototype/              ← движок эффектов + реестр
      Masks/                  ← папки масок + tags.json
      manifest.json           ← version, masks[], minAppVersion, sha256
      manifest.sig            ← подпись Ed25519
  UserMasks/                  ← как сейчас, всегда --untrusted
```

### Порядок разрешения (что показываем)

`MaskLibrary.all()` = слить, приоритет сверху вниз:
1. `Content/current/Masks` (скачанный пак) — доверенный **после проверки подписи**
2. бандл `Resources/Masks` — доверенный (fallback: офлайн / первый запуск / пак битый)
3. `UserMasks` — всегда `--untrusted`

Тот же приоритет для `Prototype/`: если пак валиден — движок грузит `Content/current/Prototype`,
иначе бандловый. Это же чинит баги эффектов без релиза.

### Доверие (обязательно)

- Пак подписан **Ed25519**; публичный ключ **зашит в приложение**.
- Проверяем: `manifest.sig` над `manifest.json`, затем sha256 каждого файла из манифеста.
- Не сошлось / нет ключа → пак игнорируется целиком, работаем на бандле. Никогда не «доверяем по HTTPS»:
  взлом CDN не должен давать выполнение кода с доступом к файлам.
- `minAppVersion` в манифесте: старое приложение не подхватит пак, требующий нового нативного API.
- Расширить `EngineFrameReceiver.isApprovedMaskURL` на `Content/current/Masks`;
  `isUntrustedMaskURL` не трогать (UserMasks остаются в жёсткой песочнице).

### Обновление

- При запуске (и раз в N часов) GET `https://dl.meetamask.com/content/manifest.json` (ETag).
- Версия новее → качаем zip пака → проверяем подпись → распаковываем в `packs/<v>` →
  переключаем симлинк `current` атомарно → чистим старые паки (оставить 1 предыдущий для отката).
- Скачивание — фоном, без блокировки UI. Обновление применяется к следующему запуску маски.
- Полный офлайн: ничего не скачалось → работает бандл. Приложение не должно ломаться без сети.

### Публикация новой маски (целевой процесс)

```
1. добавить Prototype/effects/registry/<name>.js + строку в effects/index.js
2. добавить Masks/<id>/index.html + запись в Masks/tags.json
3. make content-pack      # соберёт zip, посчитает sha256, подпишет ключом
4. загрузить пак + manifest.json на CDN
```
Ни сборки Xcode, ни нотаризации, ни релиза. 100 масок = один пак.

## Риски

- **Подмена контента** → закрыто подписью + sha256; без валидной подписи пак не исполняется.
- **Частичная распаковка** → пишем в `packs/<v>.tmp`, переключаем симлинк только после проверки.
- **Раздувание диска** → держим текущий + один предыдущий пак.
- **Рассинхрон реестра и масок** → пак атомарен: `Prototype` и `Masks` едут вместе, одной версией.
